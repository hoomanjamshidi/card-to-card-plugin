درگاه کارت به کارت ووکامرس با کارت هم‌رنگ بانک، صفحه پرداخت اختصاصی، آپلود و بررسی رسید، مهلت و لغو خودکار، پیامک ملی‌پیامک و پنل تنظیمات مدرن.

== Description ==

* کارت بانکی با رنگ و لوگوی ۳۷ بانک ایرانی، تشخیص خودکار بانک از شماره کارت / شبا
* صفحه پرداخت خصوصی با مبلغ به عدد و حروف، مهلت و دکمه‌های کپی
* آپلود رسید (عکس / PDF)، شماره پیگیری، ۴ رقم آخر کارت و فیلدهای دلخواه
* تأیید / رد رسید از پنل یا صفحه سفارش؛ حالت سخت‌گیرانه
* مهلت، یادآوری و لغو خودکار با برگشت موجودی
* پیامک ملی‌پیامک: پترن یا خط اختصاصی/اشتراکی + آزمایش اتصال
* سازگار با حساب کاربری ووکامرس، HPOS، چک‌اوت بلوکی و هر قالبی
* نگهداری / حذف خودکار فایل رسیدها

== Installation ==

1. افزونه را نصب و فعال کنید (ووکامرس لازم است).
2. ووکامرس › کارت به کارت: کارت مقصد را اضافه و درگاه را فعال کنید.
